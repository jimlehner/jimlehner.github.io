    <h2>Taguchi Loss Calculator</h2>
    <div class="webapp-content">
      <div class="webapp-text">
        <p>
          The Taguchi Loss Calculator allows users to put the otherwise theoretical ideas of the Taguchi loss function to work. By calculating the economic loss due to poor quality using a quadratic loss function, the calculator reveals that the moment a process produces parts off-target, an economic cost is incurred. This cost increases quadratically until the function reaches the specification limits, where parts are either scrapped or reworked.
        </p>

    <h2>Honest Process Capability Analysis</h2>
    <div class="webapp-content">
      <div class="webapp-text">
        <p>
          The Honest Process Capability Analysis web application allows users to calculate process capability indexes by selecting an existing dataset or uploading their own. The app calculates the four standard indexes in common use today: capability ratio (Cp), centered capability ratio (Cpk), performance ratio (Pp), and centered performance ratio (Ppk). The overview tab provides a discussion of each index, while the formulas tab outlines the equations and their terms. The app also calculates the fraction nonconforming, biased point estimate, and upper and lower interval estimates for the biased point estimate using the Agresti-Coull interval estimate method.
        </p>
