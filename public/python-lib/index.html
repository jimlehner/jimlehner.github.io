process_improvement.py

A Python library dedicated to process improvement?
Just what I was looking for!

Learn more about the library on GitHub

The process_improvement.py library serves as a free alternative to tools like Excel, Minitab, and JMP, all of which require a fee to access. Assuming a rudimentary knowledge of Python, the library simplifies the calculations and generation of figures that play a foundational role in solving problems, reducing costs, and improving quality.

Although the primary tool of the library is the XmR chart, it offers functionality for eight other process improvement tools, including capability histograms, combo charts, trended X charts, limit charts, and network analysis charts.

Hosted on PyPI, process_improvement can be installed using pip by running the following command in the command prompt:

pip install process-improvement

Combo Charts

Combo charts allow users to examine the voice of the process and the voice of the customer in a single field of view. The voice of the process is defined by the process limits on the X chart, while the voice of the customer is defined by the specification limits on the capability histogram.

Capability Histograms

Also called a process histogram, the capability histogram reveals the shape, center, and spread of a dataset in the context of the specification limits and target. This visual arrangement makes it clear whether the distribution fits within the tolerance or exceeds it.

Limit Charts

Not to be confused with a process behavior chart, a limit chart plots process data in time order in the context of the specification limits and target. This visual arrangement makes it easy to identify individual values that exceed the specification limits and examine the relationship between the process mean and target.

Network Limit Charts

Network limit charts are composed of a grid of individual limit charts that share the same y-axis. This arrangement allows for direct visual comparison between process elements performing the same task, such as machines producing the same part.

Network Analysis

A network analysis chart is composed of a grid of X charts that share the same y-axis. This allows for direct visual comparison of the means and process limits for system elements performing the same task. This approach is useful when there is a need to understand systems, as opposed to individual machines.

Taguchi Loss Function

The Taguchi loss function calculates the economic loss associated with poor quality. It provides a more accurate model of loss than the traditional approach of adhering to specifications.

Trended X Charts

As the name suggests, the trended X chart calculates process limits for data that exhibit a distinct increasing or decreasing trend. This allows for the identification of assignable causes of exceptional variation in datasets that would otherwise go unnoticed.

XmR Charts

The XmR chart is the most useful type of process behavior chart. Given a dataset composed of individual values, the XmR chart allows you to determine when it is economical to take action to improve a process and when it is economical to leave a process alone.

XmR Chart Comparisons

The XmR comparison chart allows users to compare how process behavior has changed across different process stages. This visual arrangement is useful for evaluating how effective changes have been in efforts to eliminate assignable causes.
